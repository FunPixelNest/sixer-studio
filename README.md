# Sixer Studio 🏏

A concept storefront for custom cricket jerseys — inspired by personalised-jersey shops, rebuilt as a single self-contained `index.html` (no build step, no images, no backend).

## Features

**Store basics**
- Product grid with front/back flip on hover, wishlist, search, category filters and sorting
- Quick view with live name/number preview and size picker
- Slide-out cart with quantity controls, free-shipping progress bar and coupons (`FIRST10`, `TEAM15`)
- Demo checkout with form validation and generated order IDs

**Extras**
- 🎨 **Design Studio** — 8 patterns, colour palettes or custom colours, polo/round collar, team name, player name and number, live front/back preview
- 🎲 Random design generator, ⬇ PNG download, 🔗 shareable design links
- 👥 **Team order builder** — squad table, paste a player list, duplicate-number warnings, automatic bulk pricing tiers, size breakdown, CSV export and a ready-to-send quote message
- 📏 **Size finder** — recommends a size from height, weight and preferred fit
- 📦 **Order tracking** timeline (try `SS-1024`)
- 🔴 Live-score ticker (simulated local league)
- ⏱ Sale countdown, 💬 help chat with quick answers, 🌙 dark mode
- Fully responsive; cart, wishlist and squad are remembered in the browser

All jersey artwork is drawn in SVG by code, so the page works offline as a single file.

## Run it

Just open `index.html` in any browser.

## Publish with GitHub Pages

1. Make the repository public (Settings → General → Danger Zone → Change visibility), or use a plan that supports Pages on private repos.
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
3. Your site will be live at `https://<your-username>.github.io/sixer-studio/` in a minute or two.

> This is a demo concept: no real orders are placed or charged, and the reviews are placeholders.
